# Documents

This folder is part of the [AI Use Case Discovery Agent](../README.md). The documents here explain why the tool exists, how it is built and how we worked on it. If you are new to the project, start with the use case.

| Folder | What you find there |
|---|---|
| [`01-use-case/`](01-use-case/use-case.md) | **Start here.** The problem, the users, the value, the numbers and the assumptions behind them |
| [`03-technical-design/`](03-technical-design/technical-design.md) | How the tool is built and why it is built that way. A second document covers [production readiness](03-technical-design/production-readiness.md): security, cost at scale and rollout |
| [`04-executive-summary/`](04-executive-summary/executive-summary.md) | The one-page executive summary, together with the [deck](04-executive-summary/deck.pdf) (the PDF is exported from `deck.html`) |
| [`05-how-we-worked/`](05-how-we-worked/pipeline.md) | The way we worked (spec, then tests, then code) and the framework we used to choose the use case |

The detailed specifications, which describe each component, are in [`../specs/`](../specs/README.md).
