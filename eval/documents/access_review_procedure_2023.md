# User access review: team procedure

Version 2023-03 · Owner: Information security · Status: approved

> Synthetic document for the evaluation of the Discovery Agent. Fictional company, no real data.

## Purpose

Every application's user access is reviewed so that people keep only the access they need, and the
evidence is filed for the ISO 27001 audit.

## How often

The review runs **twice a year**, in January and July.

## Steps

1. **Export the user lists.** The security analyst exports users and rights per application from
   the identity directory.
2. **Send the lists to the application owners.** The security analyst e-mails each list to the
   owner of the application.
3. **Review and mark access to remove.** Each application owner reviews the list in **Excel** and
   marks the users whose access must be removed.
4. **Approve the removals.** Removals are approved by the **line manager by e-mail** before anything
   is changed.
5. **Remove access and file the evidence.** The security analyst removes the access and files the
   signed lists in the audit evidence folder.

## Records

Personal data (names and user ids) is handled under the data protection policy. Keep the evidence
for three years.
