# NorthStar Agentic Ops

AI-augmented operational workflow prototype for **NorthStar Infrastructure Group**, a fictional 50k-employee global engineering & construction company.

**Use case: BidCheck** *(working name)*. Before NIG sends a price, BidCheck checks the bid against what NIG's own past projects and past tenders really show: what the job will really cost, where the plan is too optimistic, and what price can win while still making money. People still plan and decide; the tool reads, compares and calculates.

> Status: 🚧 work in progress (design)
